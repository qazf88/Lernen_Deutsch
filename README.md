# Deutsch üben

41 тест, 13 тем, **17 092 вправи** з українськими перекладами й поясненнями.

| Рівень | Вправ |
| --- | ---: |
| A1 | 3 133 |
| A2 | 4 866 |
| B1 | 4 255 |
| B2 | 4 378 |
| C1 | 460 |

Теми: дієслова й часові форми, займенники, іменники, відмінки, прийменники, прикметники, числівники, сталі вирази, аргументація, діалоги, порядок слів, запитання, сполучники й послідовність подій.

## Як користуватися

1. Відкрий [сайт у браузері](https://qazf88.github.io/Lernen_Deutsch/).
2. Обери тему, тест, доступний рівень і 5, 10 або 20 вправ. Пошук працює за німецьким словом або українським перекладом в обраному тесті.
3. Заповни пропуски й натисни «Перевірити». У полі може бути кілька слів або ціле речення. Переклад відкривається натисканням.
4. Enter переходить до наступного поля, а в останньому перевіряє набір. Регістр і зайві пробіли не впливають на оцінку, ä/ö/ü/ß потрібно писати точно з клавіатури.
5. «Нові речення» створює інший набір, «Повторити помилки» повторює помилкові вправи.
6. Виділи одне німецьке слово в тексті або полі введення: угорі з’явиться посилання для пошуку в Duden у новій вкладці. При знятті виділення посилання зникає; Escape також ховає його.

Автозаповнення, автокорекція, автоматичні великі літери й перевірка правопису вимкнені для полів введення. Мобільна клавіатура може показувати власні підказки незалежно від налаштувань сайту. Щоб прибрати їх, на iPhone вимкни «Предиктивний текст» у «Параметри → Загальні → Клавіатура» ([інструкція Apple](https://support.apple.com/en-au/104995)); у Gboard відкрий «Налаштування → Виправлення тексту» та вимкни «Показувати смугу підказок» ([налаштування підказок Gboard](https://support.google.com/gboard/answer/7068415)). Назви пунктів залежать від мови та версії системи.

Прогрес зберігається у цьому браузері. У статистику потрапляє лише перша перевірка набору. Якщо сторінка не оновилася, натисни Ctrl+Shift+R.
