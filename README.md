# Deutsch üben

Тренажер німецької мови з українськими підказками. Працює без сервера застосунку, облікового запису та встановлення залежностей.

## Запуск

Відкрийте `index.html` у сучасному браузері. Або запустіть локальний сервер із каталогу проєкту:

```sh
python3 -m http.server 8000
```

Відкрийте `http://localhost:8000`. Щоб користуватися з телефона в тій самій Wi-Fi мережі, відкрийте `http://IP-КОМПʼЮТЕРА:8000`. Комп’ютер має працювати, а його мережеві налаштування — дозволяти доступ до порту 8000. Зупинка сервера: Ctrl+C.

## Навчання

- Оберіть тему, тест і рівень; можна виконувати по 5, 10 або 20 вправ.
- Пошук за німецьким словом чи українським перекладом працює в обраному тесті.
- Заповніть усі пропуски. В одному полі може бути кілька слів.
- Натисніть «Переклад речення» для української підказки.
- Кнопки ä, ö, ü, ß вставляють літеру в активне поле. Enter переходить до наступного поля, а в останньому — перевіряє набір.
- «Повторити помилки» створює новий набір лише з помилкових відповідей.

Регістр і зайві пробіли не впливають на перевірку. Написання ä/ö/ü/ß зберігається: `schon` та `schön` — різні слова. Якщо допустимо декілька форм, вони явно перелічені у вправі.

У статистику входить лише перша перевірка набору. Повторна перевірка виправлених відповідей змінює підсвічування, але не бали. Час рахується лише у відкритій активній вкладці, із паузою після трьох хвилин без дій; доба визначається місцевим часом пристрою.

Прогрес і налаштування зберігаються в поточному браузері. Різні пристрої, браузери та адреси сторінки мають окремий прогрес. Якщо сховище заблоковане, вправи продовжують працювати, а сторінка повідомляє про неможливість збереження. Старий лічильник правильних відповідей відображається окремо: стара середня оцінка не містила достовірної кількості спроб.

## Перевірки

Node.js 18 або новіший; основні тести не потребують npm-залежностей:

```sh
node tests/run.js
# або
npm test
```

Браузерні перевірки додатково потребують установленого Playwright і Chromium:

```sh
npm install --no-save playwright
npx playwright install chromium
npm run test:browser
```

Можна використати наявні Playwright/Chrome через `PLAYWRIGHT_MODULE` (шлях до модуля) і `CHROME_BIN` (шлях до браузера). `SCREENSHOT_DIR` задає каталог знімків екрана. Браузерний тест сам запускає й зупиняє тимчасовий HTTP-сервер на localhost.

## Структура

- `index.html`, `style.css`, `main.js` — інтерфейс і робота з браузером.
- `core.js` — перевірка відповідей, фільтрація, перемішування, статистика й облік часу.
- `data/expansion.js` — новий словник і навчальні тести.
- `data/data.js` — явний реєстр тестів; завантажується після файлів даних.
- Решта підключених `data/*.js` — наявні вправи.
- `tests/` — регресійні перевірки логіки, усього банку даних та браузера.

Для нових вправ задавайте `answers: ['відповідь на перший пропуск', 'відповідь на другий']`. Кожному `___` відповідає один елемент масиву. `alternatives` містить повні альтернативні набори відповідей, наприклад `[['Stuhls'], ['Stuhles']]`. Потрібні також `sentence`, `infinitive`, `ua_infinitiv`, `ua_sentence`, `level`; `explanation` показується після перевірки. Текст виводиться через DOM як текст, без виконання HTML.

Перевірку складної конструкції Futur II з `lassen` звірено з [поясненням порядку слів](https://deutschegrammatik20.de/2012/07/30/leserfrage-futur-ii-von-lassen/) та [описом Ersatzinfinitiv в IDS grammis](https://grammis.ids-mannheim.de/systematische-grammatik/1615).
